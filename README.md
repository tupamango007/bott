# Telegram → Discord мост

Бот пересылает сообщения из Telegram (личные сообщения боту, группы или каналы) в Discord
и по желанию отправляет ответы из Discord обратно в Telegram.

## Возможности

- Текст с форматированием: жирный, курсив, подчёркнутый, зачёркнутый, спойлеры, код, цитаты.
  Эмодзи не сбивают разметку.
- Фото, видео, GIF, видеосообщения, документы, аудио, голосовые, стикеры. Анимированные
  стикеры отправляются как превью.
- Альбомы целиком. Файлы делятся на пачки с учётом лимитов Discord (10 файлов и лимит размера сервера).
- Геопозиции, места, контакты, опросы, кубики.
- Контекст: «переслано от …» и ответы. Если исходное сообщение уже есть в Discord, бот
  отвечает прямо на него.
- Правки в Telegram обновляют сообщение в Discord. Если после правки сообщение стало
  запрещённым, оно удаляется.
- Режим вебхука (`USE_WEBHOOK=1`): сообщения выглядят так, будто их пишет сам автор.
- Двусторонний режим (`TWO_WAY=1`): ответ (reply) в Discord на пересланное сообщение уходит
  автору в Telegram вместе с вложениями.
- Маршрутизация: разные чаты Telegram можно направить в разные каналы Discord (`ROUTES`).
- Фильтры: стоп-слова, запрещённые домены (в том числе скрытые в ссылках), удаление ссылок,
  чёрный и белый списки, антифлуд.
- Защита от `@everyone` и других упоминаний.
- Состояние (чёрный список, стоп-слова, пауза, статистика) хранится в JSON-файле и не
  теряется при перезапуске.
- Эндпоинт `/health` с реальным состоянием ботов (200 или 503).

> Удаления сообщений Telegram Bot API не передаёт, поэтому их синхронизировать нельзя.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните токены и ID
python bot.py
```

Боту в Discord нужен **Message Content Intent**: Developer Portal → Bot → Privileged Gateway Intents.
Для `USE_WEBHOOK=1` нужно право «Управлять вебхуками» в канале.

## Команды

Discord: все команды работают и как `!команда`, и как `/команда`. Нужны права администратора сервера.
Telegram: команды доступны пользователям из `ADMIN_IDS`.

| Команда | Что делает |
|---|---|
| `pause` / `resume` | Приостановить или возобновить пересылку |
| `stats` | Статистика |
| `status` | Состояние ботов, пинг, аптайм |
| `ban <id>` / `unban <id>` / `banlist` | Чёрный список Telegram |
| `addword <слово>` / `removeword <слово>` / `words` | Стоп-слова |
| `help` | Список команд |

Для всех пользователей Telegram: `/start`, `/help` и `/id` (показывает ваш ID и ID чата, удобно
для настройки).
